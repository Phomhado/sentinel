Hello and welcome!

Sentinel is a Task Manager webapp made with Tauri: A framework that allows Full-Stack development using Rust as the backend
See Tauri docs for more information: https://v2.tauri.app/ 

Sentinel allows you to see your CPU, Disk and Memory (RAM) usage, it also allows you to see the "heavier" top 10 tasks running on your machine

You also can terminate them and it will stop running. It also includes a live update (every one second) of all the tasks and information

This project is already ready for use, but it is far from how I want it to be. I plan to add more features in the future!
